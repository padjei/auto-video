description: Produce and render a professional video from a script or creative brief
---
Use the repository's video-production skill and agent workflow.
Treat everything after this command as the creative brief or script.

Required:
1. Save input to `projects/<slug>/brief.md`.
2. Run editorial and creative planning through subagents.
3. Produce a timed storyboard.
4. Create `project.json`.
5. Implement or update the Remotion composition.
6. Add captions/narration if appropriate and available.
7. Render draft.
8. Run QA.
9. Fix critical issues.
10. Render final MP4 under `out/`.

Do not stop after the storyboard unless rendering is technically impossible.
